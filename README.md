# 서비스 소개
> 내가 먹은 도시락을 공유해보세요!

## 서비스 기능
- 다른 사람들의 도시락을 구경해요.
- 내가 먹은 도시락을 공유해요.
    - 사진 업로드 및 편집
    - 도시락 메뉴 기록
    - 누구와 함께 먹었는지 기록
    - 도시락 간단 레시피 공유 (예정)
- 도시락 기록 조회
    - 월별로 내가 기록한 도시락을 조회할 수 있어요.
- 마음에 드는 도시락 좋아요 (예정)
    - 다른 사람들의 도시락에 좋아요를 눌러보세요.
- 도시락 필터링 (예정)
    - 도시락의 컨셉(간단/다이어트/귀여움/특별식 등)에 따라 도시락을 필터링해서 구경할 수 있어요.
