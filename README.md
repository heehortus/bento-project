# 서비스 소개
> 내가 먹은 도시락을 공유해보세요!

## 서비스 기능
- 다른 사람들의 도시락을 구경해요.
- 내가 먹은 도시락을 공유해요.
    - 사진 업로드
    - 도시락 메뉴 기록
    - 누구와 함께 먹었는지 기록
    - 도시락 레시피 (선택)
- 도시락 기록 조회
    - 월별로 내가 기록한 도시락을 조회할 수 있어요.

## 기술 스택
- 프론트엔드: React
